## Project Overview

A sleek weather application that provides accurate forecasts and weather data for locations worldwide.

## Technologies Used

- Weather API Integration
- Geolocation
- Responsive Design
- CSS Animations

## Key Features

- Current weather conditions
- 7-day forecast
- Location search
- Beautiful UI with weather animations
