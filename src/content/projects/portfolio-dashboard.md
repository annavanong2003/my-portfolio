## Project Overview

A creative coding project built with p5.js that generates unique, visually intriguing masks on each execution. While every mask is different, they all share a consistent artistic style, combining abstract shapes, vibrant colors, and playful patterns. The project explores randomness and conditional logic to create digital art with personality.

## Technologies Used

- p5.js (JavaScript creative coding library)
- Randomization functions (random(), conditionals)
- Canvas rendering (9:16 aspect ratio)
- Shape and color manipulation

## Key Features

- Unique mask generation: Each run produces a one-of-a-kind mask with its own character.
- Randomized elements: Position, size, line thickness, and colors vary dynamically.
- Consistent style: Despite randomness, masks remain coherent within the chosen artistic style.
- Creative combinations: Shapes, lines, and patterns blend into abstract, geometric, or cartoonish designs.
- Responsive canvas: Designed with a vertical 9:16 aspect ratio for modern display formats.
